Este repositorio agrupa la primera entrega del proyecto. Cada componente vive en su propia rama con documentación y evidencias completas.

## Contenido del repositorio
- **Modelo Lógico** — entidades, relaciones y restricciones.
- **Modelo Físico** — DDL, índices, particiones y secuencias.
- **Base de Datos Distribuida** — configuración, nodos y sincronización.
- **Queries y Población de Datos** — scripts de carga y consultas de verificación.

## Ramas principales
- `modelo_logico/`  
- `modelo_fisico/`  
- `sbdd/`  
- `queries_tablas_pobladas/`

> Cada rama contiene su **README** específico, scripts, diagramas y resultados.

## Cómo navegar
1. Cambia a la rama deseada (`git checkout <rama>`).
2. Sigue el README de esa rama para reproducir scripts y resultados.
